# homebrew-nexus

Homebrew tap for [Nexus](https://github.com/youseonghyeon/nexus) — a native macOS dashboard for your servers.

```zsh
brew tap youseonghyeon/nexus
brew trust youseonghyeon/nexus
brew install --cask nexus
```

Requires macOS 27 or later on Apple silicon. The app updates itself, so `brew upgrade` is not needed.
